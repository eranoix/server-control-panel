Server Control Panel RECOVERY

Recovery mode. Use it when the main panel stops responding. Auth requires password + recovery TOTP (a secret separate from the normal login TOTP).

First time in Recovery. Add the secret below to your authenticator app (Aegis, Google Authenticator, 1Password) and then type the current code to confirm. This TOTP is SEPARATE from the main panel's 2FA.
Manual secret:
Label it in the app as vps-manager recovery to tell it apart from the normal TOTP.
Algorithm: SHA1 · 6 digits · 30s.
To roll back the last deploy without the UI: vpsmctl rollback.
