The complete first-run sequence
  1. Install the F-Droid app on the device, if you do not have it yet (f-droid.org).
  2. Scan the QR code above in F-Droid → Settings → Repositories → QR icon — it confirms the fingerprint and adds this repository.
  3. Install vps-manager from the F-Droid app list, inside the repository you have just added.
  4. Pair the device — open vps-manager in this browser (the computer, not the phone), go to Settings → Mobile devices and generate the pairing QR there; it is a different code from this one, specific to the device.
