Architecture

A single-binary Linux control plane — what it is made of and why.

Shape

One statically linked Go binary. The entire front end is compiled into it with go:embed, so there is no asset directory to deploy, no reverse proxy required to serve static files, and no version skew between the API and the UI that talks to it. Deployment is copying one file.

LayerChoiceReason
HTTPstandard library net/http The routing needs are modest; a framework would add a dependency and a migration burden without removing any real work.
Front endAlpine.js, xterm.js, Monaco, Chart.js No build step for application code. The page is served as written, which keeps the debugging loop short.
StateJSON files + SQLite (pure-Go driver) CGO_ENABLED=0 holds, so the binary stays static and the container image stays small.
AuthJWT (HS256) in an HttpOnly cookie, WebAuthn passkeys Bearer tokens in JavaScript-readable storage are an XSS liability.

Terminal sessions

Sessions outlive both the browser tab and the server process. A PTY is allocated per session and attached to a detached multiplexer, so a restart of the control plane does not kill a running job — reattaching replays the live screen rather than starting a blank one.

Rendering is per-client. Two viewers of the same session at different window sizes each get output composed for their own viewport, instead of the whole session collapsing to the smallest connected screen.

Degradation as a design rule

Every subsystem — containers, hypervisor inventory, messaging, video, speech — is opened lazily and fails soft. A missing dependency logs a line and disables one panel; it never prevents the process from starting. A control plane that refuses to boot because a monitored service is down is the opposite of useful, since that is exactly when you need to open it.

Demo mode

The public demo runs the real binary with DEMO_MODE enabled. That flag installs a single wrapper around the HTTP mux and denies everything by default, allowing only an explicit list of read paths. Mutating verbs, terminal WebSocket upgrades, container exec and the recovery console are outside that list by construction.

The allowlist sits at the one point every request passes through, rather than being applied per route. A denylist would have been the obvious mistake: with 266 routes registered, a single new one added later would silently reopen a shell to the public internet.

Recovery path

A separate command-line tool administers the same data directory without the web UI — resetting credentials, inspecting state, rotating secrets. The failure mode it exists for is the one where the panel itself will not start, which is precisely when a web-only administration story leaves you locked out.
